# BCU menu bar companion

BCU's menu companion is a separate macOS accessory application built from `BCUStatus.swift`. Its mark is an **Inter Bold B inside a square outline with sharp corners and no border radius**. The status-bar image is a monochrome template so macOS adapts it to the current menu bar appearance; it dims when shared routing is off. The Applications icon is white on black. Both use the same vector outline derived from [Inter](https://github.com/rsms/inter), at weight 700 and optical size 14, so the font does not need to be installed. Inter is credited under its [SIL Open Font License](INTER-LICENSE.txt). `assets/BCU-icon.png` is a preview, not a required runtime image. The app has no Dock icon.

Install or repair it with `bobocodexultra menu install`. The CLI compiles Swift with Apple's `swiftc`, renders the icon and packages `~/Applications/Bobo Codex Ultra.app`, locally ad-hoc signs it, creates a per-user LaunchAgent at `~/Library/LaunchAgents/com.bobocodexultra.menubar.plist`, then opens it. No root privileges or hosted menu service are needed. `bobocodexultra menu` reopens the installed app. The menu LaunchAgent has `RunAtLoad` enabled and `KeepAlive` disabled: it starts when you log in but intentionally stays quit when you choose **Quit BCU Menu**. Use **Launch at Login** to remove or recreate its login item.

The menu shows shared/native mode and whether the local router answers its health check. It can turn shared routing on/off, open Manage Models, launch Terminal for a hidden Keychain credential prompt, open Codex Desktop or this repository, change login behavior, and quit the companion. The graphical model window has search, popular/name/context/selected sorting, scrollable rows, per-model add/remove, and default selection. Model names are displayed as `[Model Name] (Openrouter)`; provider IDs remain visible on the secondary line for identification. Changes go through the installed CLI, and Codex needs to be reopened for its model selector to reload.

The icon app and router are separate processes and separate login items. **Quit BCU Menu** closes only the icon. **Turn Off Shared Mode** restores the earlier native/Ollama desktop configuration while leaving the menu available. Turning off Launch at Login affects only the icon, not router persistence. These are deliberate so you can manage BCU without interrupting a task. The menu does not read or display your OpenRouter API key; key entry uses the terminal and macOS Keychain.

The manager fetches OpenRouter's public tool-capable catalog. If the catalog cannot be fetched, it explains the network failure; existing selected models remain in its local state. The menu's status refreshes periodically, but the Codex model picker itself loads at app startup. On this Mac the Codex desktop bundle is `/Applications/ChatGPT.app`; if installed elsewhere, the **Open Codex Desktop** action reports that it could not find the app rather than guessing.

## Usage & Costs

Choose **Usage & Costs…** to open the shared desktop/legacy OpenRouter usage report. Date filters, model search and token/cost/name sorting accompany separate reported, estimated and known-cost totals. Cached and reasoning counts are visible without double counting. Unknown prices and unreadable history show warnings instead of silently claiming a complete total. Native ChatGPT and Ollama requests are excluded.

The window refreshes local history every 15 seconds while visible. **Refresh** reads local data and cached prices only; **Refresh Prices** fetches OpenRouter's public catalog for fallback estimates. Neither operation reads your API key or makes a model call. See [Usage accounting](USAGE.md) for details.

Quit the old companion before `bobocodexultra menu install` to load an updated binary. This does not interrupt the router or require a Codex restart. The installer records its Python interpreter in the app bundle so launch from Finder/login works without shell initialization. If you move or remove that Python installation, reinstall the menu app using the replacement interpreter.

To build manually for development on macOS, use `swiftc -O -framework AppKit -framework SwiftUI BCUStatus.swift -o /tmp/bcu-menu-dev`; the packaged installer also creates `.icns`, `Info.plist` and the login item. The menu requires macOS 13 or later and Apple's Swift compiler. The router/CLI requires Python 3.14 or later for built-in zstd decompression.
